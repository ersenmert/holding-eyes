Holding Eyes - Privacy Policy

Last updated: 28 October 2026

Who we are

Holding Eyes is a private tool run by Point Lazer (Istanbul, Turkey) for its own YouTube channels only. Contact: pointlazeristanbul@gmail.com.

What data the app accesses

Only after the channel owner signs in and gives consent, the app requests these read-only Google scopes:

  • youtube.readonly - the owner's channel details and list of uploads (titles, publish dates, privacy status).
  • yt-analytics.readonly - the owner's channel and video statistics (views, watch time, subscribers, impressions, click-through rate).

The app cannot upload, change or delete videos, comments or any other data.

How the data is used

The data is used only to show the owner reports about the owner's own channels. It is not used for advertising, it is not sold, and it is not shared with any third party.

Where the data is stored

The sign-in token is stored only on the owner's own computer. Reports are stored as files on the owner's own computer and storage. No data is sent to any server run by us.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends access.

Google API Services

Holding Eyes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Changes

Changes to this policy are published on this page with a new date.
