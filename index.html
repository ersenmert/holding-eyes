Holding Eyes

Holding Eyes is a private, read-only reporting tool used by Point Lazer (Istanbul) for its own YouTube channels. It is not offered to the public.

With the channel owner's consent, it reads the owner's own channel data through the YouTube Data API and the YouTube Analytics API (uploads, views, watch time, subscribers) and shows it to the owner on the owner's own computer. It cannot upload, edit or delete anything.
